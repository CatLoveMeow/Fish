# 🐟 MUJ FISH 🐟

> **SLCM, But Better.** A lightweight browser extension designed for Manipal University Jaipur (MUJ) students to enhance their student portal experience with attendance math, CGPA forecasting, and cleaner dashboards.

---

* **[Google Chrome Web Store](https://chromewebstore.google.com/detail/muj-fish/knijkmiieojnmmchmmjblnkjbbicicgh)** — Install the extension for Chrome, Brave, Edge, and Arc.
* **[Mozilla Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/muj-fih/)** — Install the extension for Firefox and Firefox Developer Edition.
* **[Feedback, Ideas & Bug Reports](https://tally.so/r/rj7R8X)** — Submit feature suggestions, report SLCM bugs, or leave a review.

---

MUJ FISH runs **entirely locally** on your browser. It collects zero personal credentials, tracks no data, and communicates only with the official MUJ student portal.
